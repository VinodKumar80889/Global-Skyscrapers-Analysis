# 🌆 Global Skyscrapers Analysis – Power BI Dashboard

## 📌 Project Overview
Global Skyscrapers Analysis is an interactive Power BI dashboard designed to explore and analyze skyscrapers across different cities worldwide.

The dashboard provides insights into building heights, construction periods, materials, usage categories, and city-wise distribution through interactive visualizations and filters.

## 🛠️ Tools & Technologies
- **Microsoft Power BI Desktop** – Dashboard development and visualization
- **Power Query** – Data cleaning and transformation
- **DAX (Data Analysis Expressions)** – Measures and calculations
- **CSV Dataset** – Source data

## 📊 Dataset Information
The dataset contains **99 skyscraper records** with 9 columns:

- Building Name
- City
- Completion Year
- Number of Floors
- Height (Feet)
- Height (Meters)
- Material
- Usage
- Record Number

## 📈 Dashboard Features

### KPI Cards
- Total Buildings
- Average Height
- Maximum Height
- Total Cities
- Average Floors

### Visualizations
1. Top 10 Cities by Skyscraper Count – Bar Chart
2. Skyscraper Distribution by Material – Donut Chart
3. Top 10 Tallest Skyscrapers – Column Chart
4. Skyscraper Usage by Material – Stacked Bar Chart
5. Average Height by Completion Period – Column Chart
6. Average Height by Completion Period – Line Chart

### Interactive Filters
- City
- Material
- Usage
- Completion Period

## 🔍 Key Objectives
- Analyze skyscraper distribution across global cities.
- Identify the tallest buildings.
- Compare building materials and usage categories.
- Explore average building heights across completion periods.
- Enable interactive exploration through dropdown slicers.

## 📁 Repository Contents
- `Global Skyscrapers Dashboard.pbix` – Power BI dashboard file.

## 🚀 How to Use
1. Clone or download this repository.
2. Download the `.pbix` file.
3. Open it using Microsoft Power BI Desktop.
4. Explore the dashboard using the interactive slicers and visualizations.
